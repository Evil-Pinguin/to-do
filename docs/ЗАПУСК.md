# Как скопировать репозиторий и запустить Aero Notes

Приложение написано на **Python + PySide6**, все данные хранятся локально
в файле `data/notes.db` (создаётся сам при первом запуске).

Ниже два способа: через **Visual Studio** (с графическим интерфейсом)
и через **командную строку** (быстрее). Результат одинаковый.

---

## Подготовка (один раз)

1. **Git для Windows** — https://git-scm.com/download/win (при установке везде «Далее»).
2. **Python 3.9+** — https://www.python.org/downloads/
   При установке **обязательно поставьте галочку «Add python.exe to PATH»**
   (на первом экране установщика, внизу).
   Проверка: откройте командную строку и наберите `python --version`.
3. **Visual Studio 2022 Community** (бесплатно) — https://visualstudio.microsoft.com/ru/downloads/
   В установщике VS отметьте пункт **«Разработка Python»** (Python development).
   Если этого пункта нет — доустановите через Visual Studio Installer → «Изменить».

---

## Способ А. Visual Studio 2022

### 1. Клонировать репозиторий
- Запустите Visual Studio → начальное окно → **«Клонировать репозиторий»**
  (или меню *Файл → Клонировать репозиторий…*).
- В поле «Расположение репозитория» вставьте:

  ```
  https://github.com/Evil-Pinguin/to-do.git
  ```

- Выберите папку, куда скопировать, → **«Клонировать»**.

### 2. Установить зависимости (PySide6)
- Откройте *Вид → Терминал* и выполните:

  ```
  python -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt
  ```

- Альтернатива чисто мышкой: правый клик по `requirements.txt` в Обозревателе
  решений → **«Установить из requirements.txt»** (Visual Studio сам создаст
  окружение и поставит PySide6).

### 3. Запустить
- В Обозревателе решений найдите **`main.py`** → правый клик →
  **«Назначить автоматически запускаемым файлом» (Set as Startup File)**.
- Нажмите **F5** (запуск с отладкой) или **Ctrl+F5** (без отладки).

Откроется окно Aero Notes, при первом запуске создадутся заметки-подсказки.

---

## Способ Б. Командная строка (PowerShell или cmd)

Всё то же самое четырьмя командами:

```
git clone https://github.com/Evil-Pinguin/to-do.git
cd to-do
pip install -r requirements.txt
python main.py
```

---

## Если что-то не запускается

| Проблема | Решение |
|---|---|
| `python` не является внутренней командой | Переустановите Python с галочкой «Add to PATH» или используйте команду `py` вместо `python` |
| `git` не является командой | Установите Git для Windows и перезапустите терминал |
| `pip install` висит долго | Это нормально: PySide6 ~500 МБ. Подождите или добавьте зеркало: `pip install -r requirements.txt --index-url https://pypi.org/simple` |
| Окно не открывается | Запустите в терминале `python main.py` и пришлите текст ошибки |
| Карточки/шрифты выглядят иначе | Это нормально — на Windows используется Segoe UI |

## Где мои заметки?

Всё лежит в одном файле **`data/notes.db`** внутри папки проекта.
Чтобы сделать резервную копию — просто скопируйте этот файл.

---

## Сборка в .exe (по желанию)

Чтобы получить одиночный exe, который работает без Python и
которым можно поделиться с кем угодно.

### 1. Установить PyInstaller

```
python -m pip install --upgrade pyinstaller
```

> Важно использовать `python -m pip`, а не просто `pip` —
> так гарантированно попадёте в то же окружение, что и приложение.

### 2. Собрать

Выполните из папки проекта (там, где лежит `main.py`):

```
python -m PyInstaller --onefile --windowed --name AeroNotes ^
    --icon assets\icon.ico ^
    --add-data "assets;assets" ^
    main.py
```

**PowerShell** — те же ключи в одну строку:

```powershell
python -m PyInstaller --onefile --windowed --name AeroNotes --icon assets\icon.ico --add-data "assets;assets" main.py
```

Сборка занимает 1–3 минуты, это нормально.

### 3. Готовый файл

После сборки появятся папки `build/` и `dist/`. Нужное — только:

```
dist\AeroNotes.exe
```

Скопируйте `AeroNotes.exe` в удобное место (например, на рабочий стол).
Запустите — приложение само создаст рядом папку `data\` и файл `data\notes.db`
с вашими заметками. **Папка `data\` должна лежать рядом с exe** — не переносите
exe отдельно от неё, иначе при следующем запуске заметки не найдутся.

```
AeroNotes.exe      ← запускать это
data\
  notes.db         ← здесь ваши заметки
```

### Предупреждение SmartScreen (Windows)

При первом запуске Windows может показать экран
«Windows защитила ваш компьютер» / «Неизвестный издатель».
Это нормально для неподписанных exe — просто нажмите **«Подробнее»**,
затем **«Выполнить в любом случае»**.

### Частые ошибки сборки

| Ошибка | Решение |
|---|---|
| `pyinstaller не распознан как имя командлета` | Используйте `python -m PyInstaller` (не просто `pyinstaller`) |
| `FileNotFoundError: assets\icon.ico` | Убедитесь, что запускаете команду из папки проекта, где есть `assets\` |
| Сборка зависла > 10 минут | Нажмите Ctrl+C, попробуйте снова — иногда зависает первый раз |
| exe запускается, но заметки пропадают | Убедитесь, что папка `data\` лежит рядом с exe, а не внутри `dist\build\` |
